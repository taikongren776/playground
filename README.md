# 星愿奇境 · Starlight Park

使用 Three.js、Vite 和原生 JavaScript 制作的中文 3D 童话乐园。所有场景模型均为程序化生成，无需外部模型服务或后端。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

`npm run build` 输出静态站点到 `dist/`；`npm run preview` 预览生产构建。

## 操作

- 鼠标或单指拖动旋转；鼠标滚轮或双指缩放。
- 点击场景中的设施或下方卡片，选择「开始乘坐」。
- 「退出乘坐」或 Esc 恢复进入前的俯瞰视角。
- 过山车一圈为 36 秒；其他设施体验 30 秒后自动返回。
- 右上角切换昼夜；烟花按钮播放一场有限时长的烟花秀，白昼点击会自动切换至夜晚。
- 页面进入后台时动画暂停；恢复后继续，不会因为后台计时跳变。

## 实现结构

- `src/main.js`：设施配置、程序化场景、动画、射线选择、乘坐状态与昼夜灯光。
- `src/style.css`：桌面和手机响应式界面。
- `index.html`：语义化界面和 WebGL 不可用时的提示容器。
- `.openai/hosting.json`：Sites 静态部署配置，默认仅所有者可访问。

设施配置集中在 `rides`，每个设施绑定 `root`、乘客 `anchor` 与观察方向 `look`。素材复用几何体与材质；烟花结束后释放 GPU 缓冲。远程字体不可用时使用系统中文字体，不影响功能。
